# sheaf v1 (graph pipeline) — usage and status

> sheaf-core copy of the FRONTIER spike doc. Binary renamed `frontier-sheaf` → `sheaf` (ADR-014); wire format ids unchanged.
> H⁰ now follows the single `H0Policy` (ADR-015): `dim_global_rule` and `dim_strict` are gone. Timings below are from the spike build.

Build: `cargo build --release -p sheaf-cli`. Binary: `target/release/sheaf`.

```
sheaf analyze <spec.json> [--out report.json] [--k K] [--null-reps R] [--seed S] [--top N] [--method shift-invert|polynomial]
```

Without `--out` the report goes to stdout. The core (`v1::analyze`) is pure and returns `(Report, Vec<Effect>)`;
`crates/sheaf-cli/src/main.rs` is the shell that reads the spec and executes `Effect::EmitReport` (ADR-005).

## Spec `frontier-sheaf/v1` (per-edge restriction maps)

```json
{ "format": "frontier-sheaf/v1",
  "nodes": [{"id": "en", "dim": 2}, {"id": "es", "dim": 2}],
  "edges": [{"u": "en", "v": "es", "Fu": [[0,-1],[1,0]], "Fv": [[1,0],[0,1]], "label": "en->es"}],
  "x": [[1,0],[0,1]],
  "w": [[0.1, 0.0]],
  "options": {"k": 6, "null_reps": 20, "seed": 1, "top": 10} }
```

- `(δx)_e = Fv x_v − Fu x_u`, the same convention as `contract/sheafcore.py`. `Fu` is `de × dim(u)`.
- `Fu`/`Fv` omitted means identity (needs `dim u == dim v`). Endpoints are an index or a node id.
- `x` is node data, `w` an edge cochain (observed per-hop drift). You need at least one. With only `x`, `w := δx` is exact by construction (A9).
- Graph only (no 2-cells) in v1 (A10).

## Report (deterministic, sorted keys, 12 significant digits)

The top level and `h0`, `h1`, `spectral` and `hodge` carry `"method": "exact"` (ADR-013). The solver name moved to `spectral.solver`. An ordered or interval approximation layer must never write into these fields.

`h0` gives the dim, the known-kernel dim, `zero_policy` + `zero_rule` (ADR-015), `zero_tol` / `zero_tol_min` (largest / smallest per-component cut), the largest eigenvalue counted zero and the smallest counted nonzero (each with its residual), `cut_consistent_with_zero_tol`, `cut_margin_ratio` and `near_zero_ambiguous` (a flag on the same rule). Option `"h0_absolute_tol": t` sets a context-chosen permitted delta.
`h0.status` is `converged`, `not_converged` or `lower_bound_only` (lower bound wins), from `spectral.converged` and `h0.lower_bound_only`. It is separate from `near_zero_ambiguous`, which keeps its meaning: `near_zero_ambiguous: false` with status other than `converged` is not a certain h0.
`h1` is computed by rank-nullity.
`spectral` gives the k+1 smallest eigenvalues of L0, their residuals, `gap_k`, `spectral_gap`, the inner-CG stats, and the L1 check (nonzero pairs mapped by `u = δv/√λ`, residual on `L1 = δδᵀ`).
`hodge` gives the exact and harmonic shares, the CG certificate, and the nulls: iid Gaussian with the same shape (plus the analytic `h1/dimC1`), and shuffled edge values within equal stalk dims.
Rankings: `edges_by_harmonic_energy`, `edges_by_discord`, `nodes_by_abs_potential` and `nodes_by_incident_discord`.

## Spectral method (ADR-012)

Per connected component, L0 is block diagonal:
- A component with at most `dense_max` (1500) dofs gets a dense EVD of all eigenvalues.
- A larger component gets faer's thick-restart Lanczos on `P (L + σI)⁻¹ P`, where σ = 1e-6·‖L‖_bound and the inner solve is Jacobi-PCG to a relative residual of 1e-12.
- `P` projects out the exact known kernel (component constants when every edge has `Fu == Fv` injective) and the locked vectors.
- Lock and restart until a fresh run finds nothing below the current (k+1)-th value, then one Rayleigh–Ritz pass on L.
- `--method polynomial` uses `cI − L` instead, with no inner solves. It's only good on expander-like graphs.

## Harmonic extension (`--boundary`, ADR-014)
`sheaf analyze spec.json --boundary boundary.json`, where boundary.json is
`{"format": "frontier-sheaf/boundary-v1", "boundary": [{"node": "a" | 0, "value": [..stalk dim..]}, ...]}` (format optional;
unknown or duplicate nodes and wrong lengths are `P_INPUT_01`). The report gains `extension`:
`method` ("exact"), `boundary_nodes`, `boundary_dofs`, `h0_relative` (dim H⁰(X,B;F) = dim ker L_II under the report's H⁰
policy; null if an interior block exceeds `dense_max`), `unique` (h0_relative == 0), `uniqueness_rule`, `note`, `route`
(dense | cg | trivial), `converged`, `residual_rel` (certified residual), `iters`, `energy` (‖δx‖²), and `values` (every
node's value, boundary flag). If not unique, values are the minimum-norm minimiser. Without `--boundary` no `extension`
key is written, so existing reports are byte-identical.
