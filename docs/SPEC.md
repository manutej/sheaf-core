# FRONTIER Sheaf Memory — SPEC v1.18 (contract)

Status: FROZEN v1.18 (2026-10-19 Bahia; changelogs §3b–§3r). Version label `v1.18` is authoritative in every contract file (schema `$id`, module docstrings, conform.sh, Rust crate doc). Files: `SPEC.md`, `sheaf.schema.json`, `models.py`, `sheafcore.py`, `tests/` (incl. `runner.py`, `mutations.json`, `gen_mutations.py`), `conform.sh`, `envlock.sh`, `mutants_public.sh`, `rust/`, plus `../build_spec.py`, `../spec.json`, `../contradictions.py` and `tools/contract/validate.py` are **read-only for builder agents** and hash-locked in `LOCK.public` (verified by `conform.sh`). Changes go through the Eval/owner role only, with a new version number.

Purpose: a deterministic, machine-checked layer under agent-written code. Every MUST below has an ID, a check that a machine runs, and a stated tolerance. A MUST with no executable check is a defect (see review §3).

## 1. Architecture
- **Spec format**: JSON validated by `sheaf.schema.json` (JSON Schema 2020-12) + `models.py` (pydantic v2 semantic validators). Rust mirror: `contract/rust` (serde structs).
- **Core**: Python reference `sheafcore.py` (scipy.sparse) is the semantic oracle; the planned production core (NOT part of milestone m1; S-SCALE-02 roadmap, prototype in `rust2/`) is Rust on faer (round 2: 17× faster dense eig than sheaf-spectral; matrix-free Lanczos) with bindings: PyO3 (Python), napi-rs / wasm-bindgen (JS/TS), UniFFI (Swift/Kotlin), C ABI, HTTP/gRPC (tonic).
- **Julia reference**: AlgebraicJulia CellularSheaves.jl for exact global sections (LDLᵀ nullspace) as a differential oracle (SHOULD, not a gate in v1).
- **Lean 4 / mathlib**: proofs about the spec *language* (e.g. pushforward preserves global sections), never about solver numerics (future).
- Math convention (Hansen & Ghrist, arXiv 1808.01513): for oriented edge e=(u,v), (δx)_e = F_v x_v − F_u x_u; L = δᵀδ; H⁰ = ker δ = ker L; discord(e) = ‖(δx)_e‖².

## 2. Requirements (MUST = gate; SHOULD = reported, not gating)
Tolerances: δ entries ATOL 1e-9 (δ copies map entries, no arithmetic); L = δᵀδ and L symmetry entrywise within 1e-9·max(1, max|L|) (scale-aware: one ulp of a 10⁷ entry already exceeds an absolute 1e-9); PSD floor λ_min ≥ −1e-9·max(1,|λ|max); SVD rank rule: σ counted nonzero iff σ > 1e-9·max(1, σ_max); eigen rule: λ counted nonzero iff λ > 1e-10·max(1, λ_max). σ_max is the largest singular value of δ and λ_max := max|λ| over the eigenvalues of L (= the largest eigenvalue, since L is PSD by R-LAP-07; a spectrum dominated by a negative value is not a valid Laplacian) — i.e. GLOBAL maxima, equal to the maximum over connected components; the singular values / eigenvalues themselves are computed per connected component (at most one component dense at a time), never on a globally densified matrix. τ := 1e-6·max(1, σ_max) is the kernel residual scale (R-H0-08, R-META-11). Energy rel 1e-9; Rust↔Python discord ABS 1e-9.

## 5. Downstream (logged, NOT built in v1)
Ontology layer, per wiki topic `wiki/topics/ontologies.md` and Hrishi Olickel, "Just-in-Time Ontologies: What Cheap Intelligence Means for Data" (AI Engineer, https://www.youtube.com/watch?v=Fa3hQVIKShw, wiki `yt-Fa3hQVIKShw`):
1. **Just-in-time local schemas per lane** (proof-of-code, translation, sheaf-memory, …), joined by mappings rather than one universal schema.
2. **Schema-as-category** (ologs / acsets in Catlab): objects = note types, morphisms = typed edges; restriction maps compiled from schema morphisms (Δ migration) instead of learned Procrustes — gives typed, explainable maps (replaces R-NONID's learned part).
3. **CQL gluing**: pushout/colimit (Σ) of local schemas into the global one; H⁰ = globally consistent sections.
4. **Oxigraph** (Rust SPARQL store) for queries over the exported RDF.
5. **SHACL-style closed-world checks** as additional MUSTs (OWL open-world semantics is not what memory consistency needs).
